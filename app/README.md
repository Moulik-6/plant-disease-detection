# AgriScan: Plant Disease Screening & Diagnosis Web Application

Production-grade, mobile-first FastAPI web application for plant disease detection and differential diagnosis with Grad-CAM explainability and calibrated ensembling.

## Configuration & Environment Variables

All settings can be configured via environment variables or `app/config.yaml`:

| Environment Variable | Default | Description |
|---|---|---|
| `APP_CHECKPOINTS` | `ml/checkpoints/resnet50/best_model.pth` | Comma-separated paths to `.pth` model checkpoints to ensemble. |
| `APP_CALIBRATION` | *None* | Path to calibration JSON generated by `ml/analysis/calibrate.py` (sets temperature $T$ and operating threshold). |
| `APP_DB` | `app.db` | Path to the SQLite history database. |
| `APP_DEVICE` | `auto` | Execution device: `auto`, `cpu`, or `cuda`. |
| `APP_STORE_IMAGES` | `0` | Whether to store uploaded raw image files to disk (`0` = no images stored, `1` = store in `upload_dir`). |
| `APP_CORS_ORIGINS` | `*` | Comma-separated list of allowed CORS origins. |

## Running Locally

### 1. Setup Environment
```bash
# Activate your virtual environment
source .venv/bin/activate   # Linux/macOS
# or .\.venv\Scripts\Activate.ps1  # Windows

# Install application dependencies
pip install -r requirements-app.txt
```

### 2. Start the Server
```bash
# With default single model
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# With an ensemble of checkpoints and calibration:
APP_CHECKPOINTS="runs/resnet50/best.pth,runs/vit/best.pth" \
APP_CALIBRATION="results/calibration.json" \
APP_DEVICE="cpu" \
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Open `http://localhost:8000` in your browser.

## Running with Docker

### 1. Build the Docker Image
The image contains only Python code and dependencies; no model checkpoints are baked into the container.
```bash
docker build -t agriscan-app:latest .
```

### 2. Run the Container
Mount your local checkpoints and data folder as volumes:
```bash
docker run -d \
  --name agriscan \
  -p 8000:8000 \
  -v $(pwd)/runs:/workspace/runs:ro \
  -v $(pwd)/results:/workspace/results:ro \
  -v $(pwd)/data:/workspace/data:rw \
  -e APP_CHECKPOINTS="/workspace/runs/resnet50/best.pth,/workspace/runs/vit/best.pth" \
  -e APP_CALIBRATION="/workspace/results/calibration.json" \
  -e APP_DEVICE="cpu" \
  agriscan-app:latest
```

## API Endpoints Summary

### `GET /health`
Returns system status, device, loaded models, and calibration parameters:
```bash
curl http://localhost:8000/health
```

### `GET /classes`
Returns the taxonomy of all 38 unified classes with crop name, condition, and binary health indicator:
```bash
curl http://localhost:8000/classes
```

### `POST /predict`
Classifies a crop leaf image with optional Grad-CAM heatmap:
```bash
curl -X POST "http://localhost:8000/predict" \
  -F "image=@sample_leaf.jpg" \
  -F "gradcam=true"
```

### `POST /gradcam`
Returns raw PNG image bytes containing the Grad-CAM attention overlay:
```bash
curl -X POST "http://localhost:8000/gradcam" \
  -F "image=@sample_leaf.jpg" \
  --output heatmap.png
```
*Note: Returns `501 Not Implemented` if the loaded ensemble contains dual-backbone fusion models.*

### `GET /history`
Retrieves past diagnostic records from the SQLite database:
```bash
curl "http://localhost:8000/history?limit=20"
```

### `DELETE /history`
Clears all saved prediction records:
```bash
curl -X DELETE "http://localhost:8000/history"
```
